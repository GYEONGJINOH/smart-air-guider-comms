구성: ESP32 센서 노드(DHT22·INA219·PIR 3존·서보 yaw/pitch) → MQTT 브로커(TLS) → 게이트웨이(Node.js) → 백엔드(Express+Socket.IO) → 프론트엔드(smart-air-guider.vercel.app, GET /sensor 폴링). 이 페이지의 수치는 실제 하드웨어가 아닌 동일한 로직의 로컬 시뮬레이션입니다.
